Datenschutzerklärung

Stand: November 2026

Kurzfassung

PyLab setzt keine Cookies, enthält keine Analyse- oder Werbedienste und hat keine Benutzerkonten. Dein Python-Code läuft in deinem Browser und wird nicht an einen Server gesendet. Dein Lernfortschritt wird nur auf deinem Gerät gespeichert.

Verantwortlicher

Marcode (GitHub: get-marcode). Kontakt über GitHub, zum Beispiel per Issue im Projekt-Repository.

Hosting über GitHub Pages

Diese Seite wird über GitHub Pages ausgeliefert (GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA). Beim Aufruf verarbeitet GitHub technisch notwendige Verbindungsdaten, insbesondere deine IP-Adresse, Datum und Uhrzeit sowie die aufgerufene Datei, um die Seite auszuliefern und zu schützen. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO (Interesse an einer sicheren und funktionierenden Bereitstellung). Dabei kann eine Übermittlung in die USA stattfinden. Weitere Hinweise findest du in der Datenschutzerklärung von GitHub.

Python-Laufzeit (Pyodide über jsDelivr)

Damit Python im Browser laufen kann, lädt PyLab die Laufzeitumgebung Pyodide beim ersten Start vom Content-Delivery-Netzwerk jsDelivr (cdn.jsdelivr.net). Dabei erhält der Anbieter technisch bedingt deine IP-Adresse und die üblichen Verbindungsdaten. Ohne diese Datei kann der Python-Teil nicht ausgeführt werden. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Die Schriften der Seite liegen dagegen lokal auf dem Server, dafür wird nichts von Google geladen.

Lokale Speicherung im Browser

PyLab speichert folgende Angaben ausschließlich im localStorage deines Browsers. Sie verlassen dein Gerät nicht:

  • Lernfortschritt, gelöste Aufgaben und eigener Code in der Sandbox
  • gewählte Sprache und Farbthema
  • Einstellungen und Stand des Lerntimers

Das dient allein dazu, die von dir gewünschten Funktionen bereitzustellen. Du kannst die Daten jederzeit löschen, über „Fortschritt zurücksetzen“ auf dem Dashboard oder über die Website-Daten deines Browsers. Es werden keine Cookies gesetzt, deshalb gibt es kein Cookie-Banner.

Keine Weitergabe, kein Tracking

Es gibt keine Analyse-Tools, keine Werbung, keine eingebetteten Inhalte von Dritten und keine Formulare. Code, den du in PyLab schreibst, wird nicht gesendet oder gespeichert, er wird lokal ausgeführt.

Deine Rechte

Du hast das Recht auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung, Datenübertragbarkeit und Widerspruch nach den Art. 15 bis 21 DSGVO. Zudem kannst du dich bei einer Datenschutz-Aufsichtsbehörde beschweren. Da Marcode selbst keine personenbezogenen Daten speichert, betreffen Anfragen zu Server-Logs in der Regel GitHub.

Privacy policy

Last updated: November 2026

In short

PyLab sets no cookies, includes no analytics or advertising services and has no user accounts. Your Python code runs in your browser and is not sent to any server. Your learning progress is stored on your device only.

Controller

Marcode (GitHub: get-marcode). Contact via GitHub, for example through an issue in the project repository.

Hosting on GitHub Pages

This site is served through GitHub Pages (GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA). When you open it, GitHub processes technically necessary connection data, in particular your IP address, date and time and the requested file, in order to deliver and protect the site. The legal basis is Art. 6(1)(f) GDPR (interest in a secure and working service). Data may be transferred to the USA. See GitHub's privacy statement for details.

Python runtime (Pyodide via jsDelivr)

To run Python in the browser, PyLab loads the Pyodide runtime on first start from the jsDelivr content delivery network (cdn.jsdelivr.net). As a technical necessity, the provider receives your IP address and the usual connection data. Without this file the Python part cannot run. The legal basis is Art. 6(1)(f) GDPR. The site's fonts, by contrast, are hosted locally, nothing is loaded from Google.

Local storage in your browser

PyLab saves the following only in your browser's localStorage. It never leaves your device:

  • learning progress, solved tasks and your own code in the sandbox
  • chosen language and colour theme
  • learning timer settings and state

This only serves to provide the features you asked for. You can delete the data at any time, with “Reset progress” on the dashboard or through your browser's site data. No cookies are set, so there is no cookie banner.

No sharing, no tracking

There are no analytics tools, no advertising, no embedded third-party content and no forms. Code you write in PyLab is not sent or stored, it runs locally.

Your rights

You have the right of access, rectification, erasure, restriction of processing, data portability and objection under Articles 15 to 21 GDPR, and you can lodge a complaint with a data protection authority. As Marcode stores no personal data itself, requests about server logs usually concern GitHub.
